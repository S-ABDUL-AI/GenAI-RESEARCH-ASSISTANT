# 📘 GenAI Research Assistant

🚀 An **AI-powered research assistant** that lets you **upload PDFs** or **paste URLs**, and then **chat with your documents** using OpenAI’s GPT models.  

✨ Supports **three modes**:
- 🟡 **Demo Mode** → Try with sample PDF & Website (no API key needed)  
- 🟢 **GPT-3.5-Turbo** → Upload your own PDFs / URLs with your OpenAI API key  
- 🔵 **GPT-4o-Mini** → Upload your own PDFs / URLs with your OpenAI API key  


## 🎨 Features

✅ Upload **PDFs** (up to 200MB)  
✅ Paste any **URL** and analyze content  
✅ **Summarize** long documents in seconds  
✅ **Ask questions** about the document (ChatGPT-style)  
✅ **Clear chat history** anytime  
✅ **Model badges** (🟡 Demo, 🟢 GPT-3.5, 🔵 GPT-4o-Mini)  
✅ Separate panes for each mode (no conflicts)
